# 🫂 CARELOOP  
*A gentle daily care & reminder system for loved ones*

Link - https://lokesh-aim.github.io/CareLoop/


CARELOOP is a **lightweight, offline-first web application** designed to help caregivers manage daily routines (medicine, activities, exercise) for elderly parents or dependents — with a **calm UI, smart reminders, and zero complexity**.

Built using **pure HTML, CSS, and JavaScript** — no frameworks, no backend, no login.

---

## ✨ Features

### 👴 Care Receiver (Father View)
- Clean, distraction-free daily task list
- Large, accessible action buttons
- Visual feedback on task completion
- Calm animated background for comfort

### 👨‍👦 Caregiver Panel
- Add tasks with:
  - Task name
  - Time
  - Category (Medicine / Activity / Exercise)
- Generate **daily care reports**
- View **historical summaries**
- Slide-in sidebar navigation

### ⏰ Reminder System
- Browser notifications
- Audible alert sound
- Gentle background pulse animation
- Automatic scheduling based on task time

### 📅 Daily Automation
- Tasks reset automatically at midnight
- Completed & pending tasks archived
- Daily report highlights:
  - Completed tasks
  - Pending tasks
  - Areas needing attention

### 💾 Offline First
- Uses `localStorage`
- Works without internet
- No data leaves the device

---

## 🛠 Tech Stack

- **HTML5** – Structure
- **CSS3** – Animations & UI
- **JavaScript (Vanilla)** – App logic & state
- **Web APIs**
  - Notifications API
  - Audio API
  - LocalStorage

---

## 🚀 How to Run

1. Clone or download the repository
2. Open `index.html` in any modern browser
3. Allow notification permission
4. Add tasks using the caregiver panel ☰

No build step. No dependencies.

---

## 🔐 Permissions

- **Notifications** – For reminders
- **Audio playback** – For alert sounds

All permissions are local and optional.
